The code in this repository is free to use, change and share under the [MIT licence](LICENSE). The licence covers the code. It does not cover these:

- the names "Technically Not" and "TechnicallyNot.ai",
- the Technically Not logo and app icon (`build/icon.png`, `build/icon.ico`, `src/assets/logo-*.png`),
- the mascot and the pictures drawn in its style (`src/assets/devices/`).

These belong to Technically Not LLC.

## What this means for you

**You may:**

- say that your project is built on, or is a fork of, Technically Not,
- use the name to talk or write about the app,
- build the app from this code for your own use, as it is.

**Please do not:**

- give out a changed version under the name "Technically Not" or a name that is easy to confuse with it,
- use the logo, the icon or the mascot for your own version or product,
- suggest that your version comes from us or is supported by us.

If you publish a fork, give it its own name and its own icon. Also change the installer identity in `package.json` (`appId`, `nsis.guid`, `productName`), so that your build does not install over the original app.
