# Code of conduct

Be kind and be useful.

- Talk about the work, not about the person.
- Assume the other person means well, and ask before you assume.
- No insults, no harassment, no remarks about who someone is.
- Do not post other people's private details.
- If you are wrong, say so and move on. So will we.

This holds in issues, pull requests and every other place of this project.

If someone breaks these rules, write to the address in [SECURITY.md](SECURITY.md). The owner reads it, and may edit or remove comments, close a thread, or block an account.
