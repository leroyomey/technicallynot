# Technically Not hidden skills — edit here

These are Technically Not's **program skills**: the instructions Technically Not's own features depend on (the Technically Not report, `tnai` commands, known-issue fixing, how sub-agents are started). They ship inside the app and are **never shown to the user** — not on Settings › Skills, the Skills page, AI panels, threads, the activity feed, or `tnai` output. They are not SKILL.md skills, so no CLI lists them in `/skills`.

- One `.md` file per skill. Files load in name order (`10-…`, `20-…`), once, when the app starts (`desktop/hidden-skills.js`, required by `agent-hooks.js` before any panel starts). A missing folder or a broken file stops the app at launch, and `node tools/check-syntax.js` checks them too.
- Frontmatter: `name`, `description` (for maintainers only), `for: every-agent` (all agent CLIs), `for: claude-code` (added before the others, Claude Code only) or `for: opencode` (added before the others, OpenCode only: the part of the lead rules that is true for it; keep it in step with `00-lead-agent.md`) or `for: codex` (the same for Codex) or `for: source-fix` (never sent with the rules: the first prompt of a thread started by "Fix a Technically Not bug from its source…", `desktop/source-fix.js`, every CLI), optional `when: <flag>` (sent only while that user setting is on: `write-skills` = Settings › Agents › Write skills, `browser-use` = Use Claude in Chrome), and `tnai-hidden: true` (keep it: Technically Not's skill lists skip anything carrying it, and refuse to import it).
- Body: each non-blank line is sent as one line of the agent's instructions. `{{tnai-mesh-hint}}` is replaced with the `tnai` command summary from `agent-mesh.js`.
- Delivery (unchanged by editing): Claude Code — appended system prompt file; Codex — `developer_instructions` of the `tnai` profile, `for: codex` lines first (`agent-hooks.js` `launchOptions`); Cursor Agent — an always-applied rule in a local plugin; OpenCode — its own instructions file, `for: opencode` lines first (`agent-registry.js` `rules`).
- To update one: edit its file, run `node tools/check-syntax.js`, rebuild. It stays hidden. README.md itself is never loaded.
