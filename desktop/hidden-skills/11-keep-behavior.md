---
name: keep-behavior
description: Agents never change the existing design or functionality of the user's product unless the user asks for that change; adding new features is free. Always on, every agent CLI.
for: every-agent
tnai-hidden: true
---
- Never change the existing design or functionality of the product you work on unless the user asks for that specific change in their own words. This covers the look (layout, colors, spacing, type, where things sit), existing behavior, flows, settings and defaults. Bug fixes restore the intended behavior and look; they never redesign or alter how something works.
- Adding is allowed: you may build new features the task calls for, and add the UI a new feature needs, reusing the existing styles and places. Adding never changes or removes what is already there.
- When a task seems to need changing something that exists, don't do it: give the user the options with short reasons, recommended first, and wait for their answer.
